> ﴿يَا أَيُّهَا الَّذِينَ آمَنُوا إِذَا تَدَايَنتُم بِدَيْنٍ إِلَىٰ أَجَلٍ مُّسَمًّى فَاكْتُبُوهُ﴾ [البقرة: 282]

## 🌐 افتح التطبيق

**https://alkhubrani3499-sys.github.io/dhimmah/**

تطبيق عربي لتسجيل الديون: **ما عليّ** و**ما لي**، مع التسويات الجزئية والكاملة ومواعيد السداد والتقارير.

## الحسابات وحماية البيانات

- كل مستخدم يُنشئ حساباً بالبريد الإلكتروني، ويصله رمز تأكيد.
- البيانات محفوظة في **Supabase (PostgreSQL)** مع تفعيل **Row Level Security (RLS)**:
  كل مستخدم يقرأ ويضيف ويعدّل ويحذف **بياناته فقط**، ولا يستطيع أي مستخدم آخر الوصول إليها.
- الزائر بدون تسجيل دخول لا يصل لأي بيانات.

## طريقة التجربة

1. افتح الرابط، ثم **الإعدادات ⚙️ ← الحساب والمزامنة ← حساب جديد**.
2. أدخل بريدك وكلمة مرور (8 أحرف على الأقل)، ثم الرمز الذي يصل على البريد.
3. أضف مستفيداً ومعاملة.
4. سجّل الخروج وأنشئ **حساباً ثانياً**: لن تظهر فيه بيانات الحساب الأول.
